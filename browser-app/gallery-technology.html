TECHNOLOGY

Image processing you can inspect.

BoundaryLab’s browser Studio uses a Web Worker for local processing so the interface can remain responsive while it produces grayscale, edge, and styled output.

Implemented processing pipeline

01Decode source pixels
02Convert to grayscale
03Adjust and smooth
04Detect and render edges

Grayscale conversion

The worker converts RGB pixels to intensity using weighted red, green, and blue values. This intensity representation is used by the edge methods.

Brightness, contrast, and smoothing

Brightness and contrast are adjusted before detection. The smoothing control applies a separable weighted blur to reduce local noise before gradient work.

How BoundaryLab finds edges

BoundaryLab looks for places where the brightness in an image changes. These changes often mark the edges of objects, shapes, and details.

Sobel method

Sobel checks how quickly brightness changes from left to right and from top to bottom. It uses this information to find likely edges and keeps the clearest edge points.

Canny-style method

This method uses two threshold levels. Clear edges are kept first, then nearby weaker edges are added when they connect to those clear edges. This helps create more continuous outlines.

Laplacian method

Laplacian looks for quick changes in brightness in all directions. It can reveal fine details and edges, depending on the threshold setting.

Boundary visualization

The Studio can render outlines, dark edge maps, overlays, blueprints, grayscale, threshold masks, neon output, and coloring-book output. Thickness, color, inversion, and transparency are applied to the actual result pixels.
